# NASA/JPL Horizons references

These files preserve external API responses used for offline AstroEye validation, including their original computational attribution and conventions. Expected coordinates are read from the original tables, not generated by AstroEye.

See [the validation report](../../../../../../docs/architecture/astroeye-validation.md) for tolerances, measured differences, query settings, limitations, and refresh instructions. Reference data retain their NASA/JPL source attribution and are not relicensed by the project's MIT code license. API use is governed by the [SSD API policy](https://ssd-api.jpl.nasa.gov/doc/).
