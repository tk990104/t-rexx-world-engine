# Reserved Product Modules

Only AstroEye has a code package today. These IDs are reserved so navigation, state, commands, and analytics do not drift while later modules are designed.

| ID | Product name | Primary shared capabilities |
|---|---|---|
| `astroeye` | AstroEye | clock, event records, ephemeris, globe layers |
| `astrotrace` | AstroTrace | case workspace, annotations, routes, astrocartography |
| `sound-radar` | Sound Radar | radio/audio sources, geolocation, trend records |
| `cosmic-watch` | Cosmic Watch | world clock, celestial events, satellites, alerts |
| `sports-command` | Sports Command | event providers, venues, research views, AstroEye charts |
| `rc-command` | RC Command | authenticated telemetry, routes, geofences, vehicle control |
| `collector-radar` | Collector Radar | marketplace adapters, saved searches, geographic signals |
| `research` | Research Mode | local event store, citations, imports/exports, comparisons |
| `director` | Director Mode | scenes, recipes, clock replay, deterministic capture |

Reserve IDs only. Do not create empty folders or placeholder implementations until a module enters an active milestone.
