# AstroEye time explorer

Open AstroEye, save or select an event, then use **Time explorer** above the chart wheel.

- Explore six hours before or after the saved start in whole-minute increments.
- Release the slider to calculate, or use the −15 / +15 minute buttons. Native range keyboard controls are supported.
- The wheel, positions, aspects, angles and planetary hour update together. The displayed preview includes local time with zone abbreviation and an explicit UTC instant, including across daylight-saving changes.
- **Event start** restores the exact selected saved chart. Selecting another event also resets the explorer.
- **View venue** preserves the preview; moving time never moves the camera.

## Data boundaries

This is an unsaved chart preview, not a changed schedule or a replay of live feeds. The event header and globe marker retain the original source schedule. No provider requests, new saved charts, event edits or exports are generated by moving the slider. Export continues to include only stored records. Closing and reopening the panel retains the current in-memory preview; page reload does not persist it.

`timeExplorer.js` derives temporary calculation input using absolute UTC minute arithmetic, converts back to the event's IANA zone, and explicitly supplies the matching UTC instant to the event validator. This avoids guessing during repeated or skipped local hours. The original event and source provenance remain unchanged.

`workspaceController.previewTime` updates `WorldClock` to `replay` for a nonzero offset, or `event` at zero. `selectedChartId` still names the persisted kickoff chart. The optional module-state `preview` field contains only `offsetMinutes` and `calculatedFor`; `astroeye:time-preview` broadcasts the event ID and preview time for future module integration. No share-link or replay-persistence contract is introduced in this milestone.

Calculations run once per committed slider change, not on animation frames or every pointer movement. There is no auto-play timer. Existing astronomical accuracy and house/hour validation limitations in [astroeye-validation.md](astroeye-validation.md) remain unchanged. This exploratory astrology view makes no sports-outcome predictions.

## Verification

- `npm run test:platform`: unchanged storage/export, original-chart reset, camera isolation, house-system preservation, invalid offsets, six-hour limits, DST fold/gap, date rollover, deletion and selection reset.
- `node scripts/qa-astroeye-time.mjs`: isolated browser profile; slider, keyboard, buttons, chart updates, refocus/close/reopen, storage protection, responsive layout and error capture. No user records are read or modified.
